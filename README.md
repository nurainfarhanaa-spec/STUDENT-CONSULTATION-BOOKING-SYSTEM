# PROJECT TITLE
STUDENT CONSULTATION BOOKING SYSTEM

# MEMBERS
1. Nurain Farhana binti Abd.Rahman (289598)
2. Nur Aisyah binti Ahmad Shukri (307982)

# DESCRIPTION
A web-based system that simplifies consultation scheduling between students and lecturers. It allows lecturers to publish available slots, students to book appointments, and both parties to track booking statuses. The system also prevents double-booking and supports face-to-face and online consultations.
